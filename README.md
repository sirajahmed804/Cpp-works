# CodeAlpha C++ Programming Internship

This repository contains the tasks completed as part of the C++ Programming internship at CodeAlpha.

## Tasks Completed

### 1. CGPA Calculator
Takes the number of courses, grade points, and credit hours as input, then calculates the total quality points and final CGPA. Displays a summary of each course along with the result.

### 2. Login and Registration System
A simple authentication system that stores usernames and passwords in a text file. Handles new user registration (with duplicate username checks) and login verification.

### 3. Banking System
An OOP-based system with `Customer`, `Account`, and `Transaction` classes. Supports deposits, withdrawals, and transfers between customers, along with transaction history tracking.

## How to Run

Each task is a standalone `.cpp` file. Compile and run using g++:

```
g++ filename.cpp -o output
./output
```

## Tech Used

- C++
- File handling (fstream)
- Object-Oriented Programming
